# The band's sounds

- `fluidr3/`: bass and guitar sounds from the FluidR3 General MIDI SoundFont (Frank Wen), as pre-rendered by
  midi-js-soundfonts (https://github.com/gleitz/midi-js-soundfonts), licensed Creative Commons Attribution 3.0
  (https://creativecommons.org/licenses/by/3.0/). Each instrument in Ogg and MP3 (for Safari). Downloaded
  2026-10-13 with the owner's permission.
- `lm-2/`: the LM-2 (LinnDrum) drum machine samples from https://github.com/smpldsnds/drum-machines ("a collection
  of public domain samples"), in Ogg and M4A. Downloaded 2026-10-13 with the owner's permission.

# Hymns & gospel — repertoire and modes, stage by stage

Track `hymns-gospel`. Written 2026-09-18.

**Every song below carries its real status.** `IN CATALOG` is already in the
build and can be put on a rung today. `IN ARCHIVE` exists in the PDMX archive
with the content id given — it needs extracting, converting and a keep/drop
decision before it can be used. `NOT FOUND` was looked for and is not there, in
either place; it stays as a finder example rather than a plan.

**Nothing here has been listened to.** The status says a file exists and what its
metadata says. Whether a transcription is any good is the one thing no check in
this repository can decide, which is why `review.py` has a human gate.

**Modes marked `NOT BUILT`** were proposed during this session and never
implemented. They are listed with what already exists that would make them cheap.

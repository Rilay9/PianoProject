Every rule was re-implemented from the page's text in throwaway scripts under this worktree's `build/v1b/` (not committed) and run with the main checkout's `.venv` (music21 10.5.0, partitura 1.9.0) over the main checkout's catalogue (`app/public/content`, 2,020 files: 1,204 generated, 544 PDMX, 272 other real), read in place. Built test files (not real scores) were written under `build/v1b/synth/`. Every figure below is this pass's own run; nothing is copied from the writer's, the check's or the applier's reports. Where the page's text left a choice to the implementer, the choice is named as a **reading**. Nothing has been heard.

**Status words.** **validated**: the run shows the rule separates its positives from the plausible counterexamples tried. **uncertain**: what was run passes, but something that decides the rule is still untested (named). **failing**: the rule gives a wrong answer on named items.

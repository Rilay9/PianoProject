# Rules for area 1.A: validation of the corrected rules (Phase 2)

**What this is.** One validation pass over the corrected `docs/classifier/rules/area-1A.md` (FABLE.md section 2 item 3; lessons-chunk1.md items 2, 4, 5, 8 and 9), in a worktree cut from origin at 485f2be2. Results here are this pass's own runs, not earlier reports'. Nobody heard anything.

**What was run.** Scripts under `build/val/` in this worktree (not committed), over a copy of the main checkout's `app/public/content` (`catalog.json` and `scores/`, copied 2026-10-08), with the main checkout's `.venv` (music21 10.5.0, partitura 1.9.0) and, for the renderer, the main checkout's `app/node_modules` (OpenSheetMusicDisplay 2.1.2, jsdom 30.0.1):

- One script per group of rules, each implementing the corrected rule as the page writes it: `r_format.py` (sections 1, 2, 3, 5, 6, 9), `r_melody.py` (4, over `tools/classifier/score.py` and `texture.py`), `r_ledger.py` (7, 8), `ottava_m21.py` (S4 against music21), `r_acc.py` (10, 12, 13, 14), `r_chrom.py` (11, with `harmony.analyse` for the key), `r_misc.py` (15 to 22, 24, 25), `corpus_lyr.py` (20 and rule 2 of section 1 on music21's corpus), `r_repeat.py` (23: the unroller written to the spec, music21 `Expander` as witness), `r_sanity.py` (26: PS13, test 2b, beaming).
- The renderer: `osmd_acc.cjs` renders a file with OSMD 2.1.2 under jsdom (canvas stubbed) and lists each graphical note's `DrawnAccidental`; `osmd_compare.py` compares section 12's model with it; `osmd_emul.py` emulates OSMD's `checkAccidental` as read in the minified source and compares that with the render.
- Catalogue surveys: `survey_format.py`, `survey_lead.py`, `survey_a.py`, `survey_ledger.py`, `nifc_oct.py`, `survey_acc.py`, `survey_osmd.py`, `survey_misc.py`, `nested.py`, `fing_share.py`, `survey_repeat.py`, `survey_last.py`; `checkids.py` (116 catalogue ids named on the page, 116 present).

**Pipelines.** These scripts split real items by id: `pdmx` in the id gives 524 "PDMX ids", every other non-generated item 285 "other" (the check's split). The page's split is 519 PDMX and 290 other, so per-pipeline counts here can differ from the page's by those five files; totals do not.

**Statuses.**
- **validated**: the rule was run on its positives and its plausible counterexamples and its answers separated them; branches with no instance in the catalogue are named.
- **uncertain**: what remains is named (an open threshold, a witness that is not the printed page, an inherited input that fails, no real instance).
- **failing**: it gives a wrong answer on the items named.

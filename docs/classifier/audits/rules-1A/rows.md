# Rules for area 1.A: the check (Phase 2, one pass)

**What this is.** One independent check of `docs/classifier/rules/area-1A.md` (26 rules, section 1.A of `characteristics-list.md`), FABLE.md section 2 item 3. Worktree cut from origin at c42faa21. The checker did not write the rules. One verdict per characteristic, then verdicts on the writer's findings, then counts made by a script.

**What was run.** The checker wrote its own scripts under `build/aud/` in this worktree (not committed). They run over a copy of the main checkout's built catalogue (`app/public/content/catalog.json` and `scores/`, copied 2026-10-08), using the main checkout's `.venv` (music21 10.5.0, partitura 1.9.0):
- `walk.py`, `cache.py`: a raw MusicXML walk of all 2,020 notated files, written without the writer's `scan.py`. 0 errors: 1,211 generated, 524 with `pdmx` in the id, 285 other.
- `c1.py` to `c20.py`, `rep.py`, `api.py` to `api3.py`: the checks named in each row.

Every claim is labelled **measured** (by the script named) or **reading**. Nothing was heard. The rules page's own numbers that were not re-run are not restated as fact.

Verdicts:
- **OK**: right as written.
- **WRONG material**: it gives a wrong answer on real scores, or a positive example is not one.
- **WRONG minor**: a correction that does not change most answers.
- **UNSURE**: it cannot be judged on the material held.

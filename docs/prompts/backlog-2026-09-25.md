# The master backlog: every problem the audit named, mapped to a decision, a wave and a verification

Opened 2026-09-25 on the reviewer's scope correction (`audit-2026-09-25-outside.md` Part 5):
Wave A diagnosed the learning-system architecture; it did not redefine the project. The
project is the whole app, and **the audit is not complete when the architecture is
correct; it is complete when the resulting learner experience is substantially better.**
This file is the living list that stops any area from disappearing because another was
diagnosed first. One row per problem; a row is closed only when *Verified?* says how.

**Columns.** *Source*: A-n = the outside audit's twenty-point procedure, point n; D = the
diagnosis of 2026-09-25 (its problem number or decision); T36a/b/c, T35 = the traces (their
finding ids); P21 = the plan of 2026-09-21's open items; O = the owner's own words with the
date. *Diagnosed?*: yes when a trace or the diagnosis names the mechanism with evidence;
partly when only the symptom is on record; no when it has not been looked at. *Decision*:
fix / build / rewrite / exclude / design (a design review before any build) / judge (a
reader decides from notation) / owner (a product choice not yet taken). *Wave*: B is
running; the later letters are the plan's waves after B (`plan-2026-09-25.md`, "After
Wave B"). *Verified?*: pending, or the test, picture or reader that closed it.

**How to read the waves.** C the learning and evidence architecture, preceded by the
skill-and-demand vocabulary design (C0) because lesson rewriting and generator validation
both depend on it; D content and generator quality; E the repertoire corpus and excerpts;
F lesson curriculum and content; G musical identity, style and the repertoire experience;
H the final pedagogical and UX audit, including hearing. The grouping may change when a
dependency says so; the rows may not disappear.

## What closes a row

A row's *Verified?* names the test seen red then green, the picture opened and read, or
the reader's line, and the wave that did it. A row moved to a later wave keeps its id. A
new problem found by any task is added with its source before the task's report is
accepted. The reviewer's question stands over the whole file: would a competent piano
teacher say the material is musically sensible, the progression makes sense, the feedback
is honest, the practice adapts to the learner, and the interface supports learning to play.

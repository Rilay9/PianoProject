## The goal, in the orchestrator's words

An import today ends in a success toast and an assign sheet; what the converter inferred is a note the learner cannot act on, the hands can be corrected only through a function no screen calls, and a piece found later in the Library is a row like any other. After X3 an import opens into one sheet that says, in learner words, what the app read from the file and what it guessed (the hands split by shape, the tempo the converter chose, the key it estimated), offers the two corrections a learner can make with certainty — *the hands are the other way round* and *this is how fast it goes* — and then asks where the piece belongs, exactly as the assign sheet asks today, with the same rule: putting it on a rung records no evidence and meets nothing. The conversion note follows the correction: once the learner has said which hand is which, the note says the hands are theirs. The Library shows an import's state in words (read from the file; the hands corrected; measured on the corrected score; the tempo stated) and the placeholder sheet stops printing ids. Nothing here offers an import automatically: the import is the learner's own chosen material until the app has measured it and a rung's gate admits it (L113 is X1's), and X3 says so on the sheet.

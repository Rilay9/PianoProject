## The goal, in the orchestrator's words

The review's repertoire retention offers any learned piece unplayed for `REPERTOIRE_WINDOW_DAYS`, whatever the learner's project says. A learner who paused a piece or put it away on the project sheet then meets *Keeping this piece playable* on Today: the app's sentence contradicts the learner's stated intention, which the lifecycle exists to hold. The reviewer ruled it (G82): once the session consumes the lifecycle, `paused` and `retired` suppress automatic retention offers, and this is the narrow seam that does it — the session's retention reader, the first consumer of a project. Nothing else starts reading projects.

## What is decided

1. **Where the read happens.** Today reads the projects where it reads its other stores: `allProjects().catch(() => [])` joins the `Promise.all` before `buildSession`, passed as a new optional `BuildInput.projects?: readonly ProjectRow[]`. Absent (a caller that passes none, a store that cannot be read): nothing suppressed, the session as before. The session never opens the store itself; it stays a function of its input.
2. **What the reader does.** In `review()`'s learned-piece loop, the piece's project is `projectIn(projects, { itemId: piece.itemId, material: materialOfItem(item) })` — the identity the lesson page and Progress already use (a row of the same material first, whatever id it was made under; else the id's own row; never another id's id-only row). A project in `paused` or `retired` skips the piece before `due` sees it. Every other case — no row, `saved`, `learning`, `polishing`, `performance-ready`, `maintaining`, `refreshing` — leaves the offer exactly as it is. Not a filter on `learned` upstream: `learned` also serves the repertoire slot's *a piece you know*, which the ruling did not touch (item 4).
3. **Silent.** No line, chip or *paused, so not offered* on Today. The learner said it on the sheet; nothing repeats it. Whether Today should ever say so is a question for the handoff, not a thing to build.
4. **Not G1d's, unchanged byte for byte:** the repertoire slot's fallback (*a piece you know*: `repertoire()`, `uncountedFirst`), skill retention, the exposure rule, `learnedPieces`, `ProgressRow.status`, the encounter and contact reads, X1's runner and its stored run, the project sheet, Progress, the Library, Plan, the lesson page.

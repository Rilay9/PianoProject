# Readable-score review index for Fable

This is the master pointer/status sheet for the song-only MusicXML review.

Authority for the direct shipped-score pass: `claude/readable-scores@c1556d70`.

Detailed notes live in:
- `SONG-CANDIDATE-SCORE-READS.md` — first authored/parsed pass, mainly core.
- `READABLE-SCORES-CORE-ADDENDUM.md` — direct shipped-score corrections across the core.
- `READABLE-SCORES-GENRE-ADDENDUM-1.md` — Stage 5–7 named style/texture reads.
- `READABLE-SCORES-ADVANCED-ADDENDUM.md` — Stage 8–9 named/project reads.
- `READABLE-SCORES-REMAINING-TRACKS-ADDENDUM.md` — early branches + technique/classical checks.
- `READABLE-SCORES-SHELF-PROJECT-ADDENDUM.md` — lighter review standard for project/shelf material.

## Status vocabulary

- **GREEN** — direct reads support the current pedagogical use; only normal file/source verification remains.
- **AMBER** — useful repertoire exists, but primary/transfer/stretch/excerpt roles need cleanup.
- **RED** — current song list does not honestly demonstrate the named acquisition target, or contains a concrete score/placement defect.
- **PROJECT/SHELF** — complexity is intentional; do not apply narrow acquisition purity tests.

“Reviewed” does **not** always mean every title was read to the last bar. The detailed notes say when a whole current set was read versus representative/high-risk reads. Never promote a score based only on this index; use the corresponding detailed note.

# Highest-payoff Fable song fixes from the direct reads

1. Replace/fix the **false literal examples** first: `rock.4`, `jazz.4`, `blues.4`, `2.2`, `2.3`, `3.5`, `chords-pop.7`, `latin`/`latin.6` montuno coverage.
2. Reclassify existing good music instead of deleting it: one-staff standards become **TRANSFER lead sheets**; hard authentic works become **STRETCH/PROJECT**; clean passages become **EXCERPTS**.
3. Preserve the areas that direct reading validated: 2.1 authored HT pieces, 3.2 authored chord songs, 3.3 Greensleeves minor work, waltz-bass Greensleeves, hymns.4 SATB, classical.5, technique.4/5, rock.5 Annie’s Song, blues.6, Joplin School of Ragtime, jam.7 lead-sheet workflow.
4. Whenever a rung names a thing the learner *does* — transpose, improvise, arrange, memorize, trade fours — verify the **task workflow**, not whether the static MusicXML mysteriously contains the learner’s future action.
5. Whenever a rung names a thing the score *is supposed to contain* — power chord, walking bass, shell voicing, montuno, pedal mark, Alberti, dominant 9 — require at least one direct score/excerpt that visibly contains it.

This index should be Fable’s starting map; the detailed addenda carry the bar/note evidence behind each call.

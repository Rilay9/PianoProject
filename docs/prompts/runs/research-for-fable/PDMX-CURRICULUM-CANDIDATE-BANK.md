# PDMX curriculum candidate bank for Fable / XML review

This is a **pre-XML-screen candidate bank**, not a keep list and not a claim that these scores teach the named thing.

Purpose: give the owner/Claude a large, useful set of PDMX files to extract/dump so an independent music read can promote, reclassify, excerpt, or reject them.

The historical genre plans already searched the 254,077-row PDMX index. An entry marked **archive-confirmed** below therefore means the title exists in PDMX and the example CID was recorded by the old quarry. It does **not** mean the arrangement is good, that the example CID is the best of its duplicate copies, or that its notes actually contain the curriculum target.

For a title with 2–4 archive copies, **dump every copy if practical**. The example CID below is an address, not a winner. Arrangement choice is one of the things this pass is trying to improve.

Use `READABLE-SCORES-REVIEW-INDEX.md` for the current shipped-score verdicts. In particular, do not repeat the old failure mode: a blues title does not prove twelve-bar form, a jazz lead sheet does not prove written comping, a Latin title does not prove montuno, and a rock-like title does not prove a power chord.

# 4. Full-index searches the old plan did not do well enough

These searches should run against the local PDMX metadata/index and, where feasible, against parsed MusicXML features rather than title text alone.

## Named texture searches

Return the top ~20 metadata candidates for each, then XML-dump the best 5–10:

- **power chord / open fifth** — repeated simultaneous root+fifth dyads, third absent; title search is secondary.
- **Alberti bass** — repeated low-high-middle-high accompaniment cell under independent melody.
- **ordinary broken-chord accompaniment** — chord tones sequentially unfolded, without falsely calling every arpeggio Alberti.
- **walking bass** — mostly monophonic LH line with beatwise motion through chord tones/passing tones under independent upper texture.
- **oom-pah / stride / waltz bass** — classify separately; do not use one `left-hand-pattern` detector as proof of all three.
- **montuno** — repeated syncopated chord/interval pattern aligned against clave; search Latin metadata only as a candidate generator, not evidence.
- **tumbao** — bass-pattern candidate, separate from montuno.
- **shell voicing** — literal reduced chord voicing, especially root+3rd/7th or guide-tone pair, not generic seventh chords.
- **rootless voicing** — chord context says one root while played voicing genuinely omits it.
- **quartal voicing** — stacked fourths in a harmonic/comping context.
- **dominant 9 / maj9 / min9 / add9** — inspect MusicXML harmony kind/degrees and written pitches.
- **pedal notation** — actual pedal start/change/stop elements, not simply a piece that is usually pedalled in performance.

## Useful structural searches

- clean 12-bar chorus
- explicit pickup/anacrusis at beginner level
- short two-staff SATB/hymn settings
- short melody+chord-symbol charts suitable for arranging/transposition
- pieces with one clean modulation/key change
- pieces with a single meter change that can teach the event without being a 150-bar showpiece
- compact swung piano arrangements with explicit written comping

# 6. What the next reviewer will decide

After the XML exists, each candidate gets one of these roles:

- **PRIMARY** — a clean first real-song example of the rung's named score fact.
- **EXCERPT PRIMARY** — whole score is too broad/hard, but a passage is excellent acquisition material.
- **TRANSFER** — good real music using the skill in a less isolated context.
- **STRETCH / PROJECT** — musically worthwhile but intentionally well above acquisition cleanliness.
- **TASK SUBSTRATE** — appropriate score/chart for a learner action such as improvising, arranging or transposing; it does not need to contain the future action itself.
- **REJECT** — wrong texture, poor transcription, wrong difficulty, misleading metadata, bad edition, or simply worse than another PDMX copy.

The goal is **not** to maximize song count. It is to have several genuinely different good choices at each rung, with at least one honest primary wherever the rung names a concrete score texture.

U110a, the exposure measured on the pruned-only build: a stage shortened by height alone after the reshape ladder has run out
===============================================================================================================================

What this is. The scratch spec that measured it, run once on the pruned-only build (the outside builder's f11cd7c6 code,
before the narrowed exception), kept here as the measurement that earned the exception. The committed case that replaced
it is the `it.each` over 700, 600 and 560 in tests/unit/windowRendererStage.test.ts, which reads the same ink and is red on
the pruned-only build and green with the exception (docs/prompts/runs/U110a/ENTRY.md).

Where it ran. The stood-in engraver of tests/unit/windowRendererStage.test.ts (the same fixture as the U110a case: two bars
asked, bars 22 engraver units wide, every bar from the third on taller), a stage 342 wide whose height the spec sets. Nothing
here was measured in a browser. The numbers are the stand-in's own arithmetic, not the renderer's on a device.

What it does. Opens at a stage height inside the band where the plan's reserve refuses the third row and the drawn rows fit
it. The ladder runs out with three rows drawn (ladder n 6). Then it shortens the stage by height only (width, zoom and asked
count unchanged), lets the stage observer refit, and reads each drawn row's ink: the wrapper's top plus the transform's
translate for the ink's top, and the stood-in svg's height times the transform's scale for its extent.

What it shows, on the pruned-only build (output below). Shortened to 700, 600 or 560, the three rows are held and each is given an
even share of the stage by packSlots (233, 200, 187), while the rows are 232, 232 and 267 tall; each row's ink runs into the
next one's by the amounts printed (positive = ink runs into the next row). Shortened to 800 or 500 the engraving zoom moved,
which resets the ladder, and the shape changed to two rows with no overlap. The 820 line is the control: the stage as it
was, nothing shortened, the rows' ink 36 and 1.3 apart.

What it does not show. Whether the browser meets this state: it needs a spent ladder (Twinkle at 342 x 740 with Bars 3 spent
it on every one of the five loads traced) and then a height-only shortening that does not move the engraving zoom. In the
traced Twinkle load the stage shortened twice while the ladder was spent and the zoom moved afterwards, so that load shows
three rows held for five passes with no ink read in them (checks-3203626b.txt, B, passes 12 to 16). U110's exception took the
row away in this state; that is by reading `settleShape` as it stood at the base, not a run: this fixture does not reach
"ladder spent with three rows drawn" on the base, because the base drops the row at the moment the ladder runs out.

The narrowed predicate, now built. `packSlots` already decides "unsafe packing" itself: it packs the rows at their own
heights only when their sum with the gaps is under the stage's height, and gives even shares otherwise. `settleShape` drops
the look-ahead row of a spent ladder only when that sum is not under the stage (`rowsFitStage`), read from the fit that has
just drawn the rows.

THE SPEC (scratch, as run on the pruned-only build)
---------------------------------------------------

describe('EXPLORE2 u110a', () => {
  function piece(): ScoreModel {
    return makeModel(
      Array.from({ length: 48 }, (_, index) => ({ onset: index, notes: [note({ midi: 60 + (index % 12) })] })),
      { handsPresent: { R: true, L: true } },
    );
  }
  /** Each drawn row's ink, top and bottom in stage px, from the wrapper's top, its transform and the stood-in svg's height. */
  const inkOf = (stage: Stage): { bars: string; wrapTop: number; wrapHeight: number; inkTop: number; inkBottom: number; ahead: boolean }[] =>
    [...stage.el.querySelectorAll<HTMLElement>('.score-buffer.is-front:not(.score-probe)')]
      .map((b) => {
        const svg = b.querySelector('svg');
        const t = /translate\((-?[\d.]+)px, (-?[\d.]+)px\) scale\(([\d.]+)\)/.exec(b.style.transform);
        const top = Number.parseFloat(b.style.top);
        const y = t ? Number(t[2]) : 0;
        const s = t ? Number(t[3]) : 1;
        const h = Number(svg?.getAttribute('height') ?? 0);
        return { bars: b.dataset.bars ?? '', wrapTop: top, wrapHeight: Number.parseFloat(b.style.height), inkTop: top + y, inkBottom: top + y + h * s, ahead: b.classList.contains('is-ahead') };
      })
      .sort((a, b) => a.wrapTop - b.wrapTop);
  const show = (rows: ReturnType<typeof inkOf>): string => {
    const overlap = rows.slice(1).map((r, i) => Math.round((rows[i]!.inkBottom - r.inkTop) * 10) / 10);
    return `${rows.map((r) => `${r.bars}${r.ahead ? 'G' : ''}[wrap ${String(r.wrapTop)}+${String(r.wrapHeight)} ink ${r.inkTop.toFixed(1)}..${r.inkBottom.toFixed(1)}]`).join(' ')} overlaps ${JSON.stringify(overlap)} (positive = ink runs into the next row)`;
  };
  it('explore2', async () => {
    const out: string[] = [];
    for (const H2 of [820, 800, 700, 600, 560, 500]) {
      FakeOsmdView.all = [];
      document.body.replaceChildren();
      observers.length = 0;
      frames.clear();
      idle.length = 0;
      FakeOsmdView.bars = Array.from({ length: 12 }, () => 22);
      FakeOsmdView.rise = Object.fromEntries(Array.from({ length: 10 }, (_, index) => [index + 2, 3]));
      const stage = stageOf(342, 820);
      const renderer = await WindowRenderer.create({ container: stage.el, model: piece(), musicXml: '<score-partwise/>', barsPerWindow: 2 });
      renderer.showStep(0);
      renderer.fitToStage();
      await settle();
      const f0 = renderer.debugFit() as { slotCount: number; zoom: number; shapeChanges: unknown };
      const before = `slots ${String(f0.slotCount)} zoom ${String(f0.zoom)} ladder ${JSON.stringify(f0.shapeChanges)} ${show(inkOf(stage))}`;
      stage.box = { width: 342, height: H2 };
      observe();
      await settle();
      const f1 = renderer.debugFit() as { slotCount: number; zoom: number; shapeChanges: unknown };
      out.push(`H2 ${H2}: BEFORE ${before}\n        AFTER slots ${String(f1.slotCount)} zoom ${String(f1.zoom)} ladder ${JSON.stringify(f1.shapeChanges)} ${show(inkOf(stage))}`);
      renderer.dispose();
    }
    const fs = await import('node:fs');
    fs.writeFileSync('../build/u110a/explore2.txt', out.join('\n') + '\n');
  });
});

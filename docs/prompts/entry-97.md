## The mechanisms, and the tests that told them apart

**The unchecked phrase (finding 1).** *Premise checked at the lines.* The brief's policy — "continue drawing within `PROMISE_ATTEMPTS`, return the first window that yields a valid candidate" — was already D1's loop: the candidate window opens only at the first valid draw (`attempt > firstValid + CANDIDATE_WINDOW`), and until then the loop runs on to the budget. So `chooseCandidate` returned `undefined` in exactly one case, a whole budget with no valid draw, and then `compose` returned whatever the last draw had left in `rightBars`/`leftBars`. *Hypothesis:* that fall-through is the only way an unchecked phrase leaves version 2. *Alternative:* a valid-looking chosen phrase could still break the hard layer or a promise. *Test:* read every returned phrase back from its MusicXML and check it independently of the generator (`brokenOnThePage`: `hardViolations` on the page's model, each promise counted on the written notes). On D1's `compose` the three cases that reach the zero-valid path each came back with a phrase that broke the rule named in the red line (below); on D1a they throw `SightReadingRefusal`; the valid cases' pages break nothing at either version. *Change:* the fall-through became a refusal carrying its reasons (`refusalReasons`: what was asked, the promises and rules with the draws spent, what the draws broke, and `unrealisable`'s own sentences). Nothing else in the search moved, so version 2's phrases where a valid draw exists are D1's note for note (the distribution suite and the promise suite green unchanged).

**How often the path is reached.** *Sweep* (`runs/probe-sweep.txt`): every level, each hand (R, both, L), 4/4 and 6/8, no option and each control on and off, the realisable ones (`unrealisable` empty): 536 option sets, six seeds each, 3,216 phrases. Every phrase found a valid draw; of 49,930 draws that kept their promises none broke the hard layer — version 2's walk respects the cap and the tie rule by construction, so `hardViolations` is a check that has not yet fired on a promise-keeping draw there. *The rarest recipes* (`runs/probe-exposure.txt`, 2,000 seeds each): level 2's right hand in G with the raised fourth, ties, dotted quarters, skips and eighths needed at most 1,238 draws to its first valid; the two-hand version with a ledger line, at most 1,905; row 4's accidental, at most 93.

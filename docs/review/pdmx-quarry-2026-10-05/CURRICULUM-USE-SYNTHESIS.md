# Curriculum-use synthesis from the PDMX quarry

Branch: `chatgpt/pdmx-dump-2026-10-05`
Date: 2026-10-05

Governing model: learner deficiency first; then `CONTROL → MODEL/TRANSFER → MUSIC → INDEPENDENCE`. This file is an input to the Fable `ABILITY-MAP.md`, not a replacement for it.

A quarry hit is useful only if it supplies a named learner-facing station. Generated material is kept where isolation/repetition/unseen material is the right job; real notation is preferred where model/transfer/music authenticity matters.

## 1. Blues / boogie

### Learner need
Move from isolated blues vocabulary to playing a right-hand idea over a complete form and then to self-directed chorus playing.

| Station | Recommended supply | Why |
| --- | --- | --- |
| CONTROL | Existing/fixed generated blues riff, boogie and turnaround exercises | isolate one vocabulary item, transpose/repeat safely |
| MODEL/TRANSFER | **Original Jelly Roll Blues** selected short phrases; **Pinetop's Boogie Woogie** selected LH/RH texture; **Blues Riff in C** complete 12-bar score | authentic historical vocabulary plus a clean full-form bridge |
| MUSIC | retained full blues/boogie pieces already in curriculum; Pinetop where level permits | sustained musical use rather than one cell |
| INDEPENDENCE | learner supplies own LH pattern/form and creates RH chorus, then transposes/repeats | closes the Fable gap: accompaniment + idea without supplied texture |

Do not replace generated control with Pinetop/Jelly Roll. Their value is authenticity and transfer; the clean generated item remains better for isolation.

## 2. Jazz cycle

Use a progression of increasingly open substrates rather than one standard for everything.

| Stage/job | Recommended real material | Role |
| --- | --- | --- |
| early chart cycle | **After You've Gone** | compact melody + chord symbols; learner supplies shells/comp/bass |
| jam/comping bridge | **St James Infirmary** | sparse chart, useful for comping and walking-bass tasks |
| Latin-jazz bridge | **Blue Bossa** | melody/chords substrate; not source for bossa accompaniment definition |
| later full cycle | **There Will Never Be Another You** | melody → voicing → bass → solo → intro/ending → solo-piano realization |
| solo-language analysis | **Autumn Leaves transcription** | phrase/motif/chord-approach analysis, not acquisition score |
| voicing/reduction model | **Fly Me to the Moon** arrangement | harmonized melody/voice-leading; do not use as evidence for minor ii-V-i without harmonic check |

Generated/theory CONTROL remains appropriate for shells, ii-V-I, guide tones and named voicing tasks. Real charts should take over once the learner must choose texture and navigate form.

## 3. Latin

### Habanera/tresillo
- CONTROL: sourced generated cells, independently checked.
- MODEL: **Por Una Cabeza** for habanera; retained printed tresillo model for the contrasting cell.
- MUSIC: tango/Latin repertoire already admitted at appropriate level.
- INDEPENDENCE: learner identifies/chooses the correct cell and applies it in a new harmonic frame.

### Bossa
- CONTROL: one or more **sourced bossa coordination patterns**, not a single invented universal rhythm.
- MODEL/TRANSFER: **Garota de Ipanema `QmRWD...`** — real two-staff written accompaniment under melody.
- APPLICATION/MUSIC substrates: **Só Danço Samba** and **Corcovado** — melody + symbols, intentionally leaving the accompaniment to the learner.
- INDEPENDENCE: learner selects/adapts a taught bossa pattern to one of those lead sheets without a fully written accompaniment.

This means A7c.3 need not remain globally source-blocked, but the exact control pattern still requires a build-brief source + onset/duration contract.

### Cuban piano
- CONTROL: only after a named figure is sourced precisely.
- MODEL/MUSIC: **La Negra Tiene Tumbao** is the strongest current real score candidate.
- Terminology must distinguish guajeo / montuno / tumbao / ponchando by actual note behavior; title alone does not classify the pattern.
- INDEPENDENCE: learner chooses/constructs a compatible ostinato over a chart and maintains it through harmony/form.

### Argentine tango
- MODEL/MUSIC: **Por Una Cabeza**, **Adiós Nonino**; Libertango candidate where personal-library/curriculum admission allows.
- Use real excerpts for articulation, ostinato and texture; generated cells only where a single rhythmic element needs isolation.

## 6. Rock

## 10. Ragtime

- CONTROL: isolated generated/simplified syncopation and LH pattern where needed.
- MODEL: **Harlem Rag** for broad authentic ragtime texture/form; **The Ragtime Dance** for observable accented interruption/continuous-texture contrast; **Sunflower Slow Drag** as a slower authentic alternative if level placement benefits.
- MUSIC: existing/admitted ragtime repertoire at appropriate rung.
- INDEPENDENCE: learner preserves steady LH/form while managing syncopated RH, then performs/memorizes a complete strain/piece.

Specific `stop-time` terminology stays source-gated unless a direct definition is supplied; the observable rhythmic contrast is usable regardless.

## 12. Dispatch rule

Before any content or generator task is dispatched, its brief should answer:

- learner deficiency;
- station supplied (`CONTROL`, `MODEL/TRANSFER`, `MUSIC`, `INDEPENDENCE`);
- why this source type is appropriate (generated / excerpt / lead sheet / full arrangement / external task);
- exact retained material or exact generator family involved;
- source/definition for any named musical figure;
- what is structurally checked and what remains self-checked/unverified as music;
- completion condition at the learner level.

If a task cannot answer those, it is maintenance without a curriculum consumer and should not be dispatched.

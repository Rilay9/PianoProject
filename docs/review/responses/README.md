# Reviewer responses

One file per handoff, created by the outside reviewer, named by the seven-character HEAD the handoff quoted (`0b39088.md`). First line: the HEAD reviewed. Then a table — `#`, status (BLOCKING / FIX-FORWARD / ACCEPT / QUESTION / SUPERSEDED), finding, where verified at that HEAD, what the orchestrator should do — and a list of QUESTIONs for the owner. The orchestrator never edits these; its dispositions go in the next `../current.md`.

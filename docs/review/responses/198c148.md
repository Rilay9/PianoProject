## Required change — Q65 minimum semantics

The map describes itself as the **auditable minimum checks for a seam**. Therefore the minimum should be the smallest set that can discriminate the mechanisms reached by the changed paths, plus universal cheap guards such as typecheck/lint/build where they genuinely apply.

It should **not** encode the full default Playwright suite merely because the owner's 2026-09-27 rule used that as the safe landing rule before the map existed.

Use this split:

- **seam/path map:** targeted discriminating unit/content/e2e specs and required build/type/lint checks;
- **merged integration CI:** full unit and full default Playwright suites, plus the other repository-wide gates;
- **fallback for an unmapped path:** keep the conservative full suites exactly as implemented.

For broad shared infrastructure where targeted coverage cannot honestly bound the reach, the map may still name the whole suite. But that should be justified by the module's fan-out, not inherited automatically from the old blanket rule.

Concrete correction:
- revisit patterns currently using `e2e: "*"` solely because of the 2026-09-27 blanket rule;
- where `docs/08` and the recent landing chains name discriminating specs, encode those specs as the minimum;
- keep full-suite CI as the final integrated-tree proof;
- keep the map additive: judgement may always add checks for cross-cutting risk.

This preserves the purpose of Q-tooling: reduce duplicate work without reducing verification.

## Additional finding — docs coverage

The catch-all `docs/** -> no checks` rule is too broad for machine-contract docs now that some files under `docs/` are executable review/tooling inputs.

Do not make every docs edit run app CI, but ensure specific machine-read paths override the catch-all, including at least:
- generated prompt views / their canonical sources;
- `docs/prompts/checks.json`;
- any test-map/record file that a script or test actually parses.

The specific patterns should win by union; the generic docs rule can remain empty for prose/review traffic.

This is part of the same Q65 correction, not a second architectural seam.

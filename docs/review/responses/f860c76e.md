3. **How should the session choose/offer material for that purpose?**

Placement:

- **X46 owns the semantic/product trace for (1) and the chooser consequence in (3).** Its session-item contract already asks “why now?” and “what can count?”, so it is the right place to discover whether an explicit application target is actually required by the learner flow and whether the current offer ignores it.

If X46 proves a stable target must persist, place it in the smallest existing domain truth that naturally owns it; only create a new field/model if existing authored requirement/session truth cannot represent it honestly.

This avoids replacing the old song-count proxy with a schema-first proxy.

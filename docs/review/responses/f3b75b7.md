The same predicate feeds the E0 learner gate in `swapOptions` (`session.ts:1444-1480`) and the session offer paths, so an unrelated track can make material appear copeable without skill evidence.

Do not use JSON traversal order as curriculum progress. Add a regression with two sibling tracks proving that a demand taught on track A is not taught on track B, while it is available to a learner who actually reached the teaching rung. Re-run the gate consumer tests and the three learner diaries after the change.

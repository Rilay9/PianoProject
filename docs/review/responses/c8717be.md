## Required change

### BLOCKS NEXT BRIEF — put every automatic session-card offer behind the same teaching-use admission

The implementation gates every current caller of `eligibleFor`, but D3a's learner-facing contract is broader: a music-promising generated item without affirmative teaching-use approval must be absent from **every automatic offer**. The exact implementation and its own exhaustive probe show that this is not yet true.

At `c8717be`, `wantsOf` in `app/src/curriculum/session.ts` takes authored rung options directly for `runs`, `done`, and `measure`; fallback rung and prerequisite steps also take those options directly; jam selection takes lesson options directly; and the exposure path is likewise outside `eligibleFor`. Those paths apply usability filtering, not the D3a teaching-use admission. The supplied `probe-card-after.txt` records 23 automatically offered card rows with unapproved music-promising generated items, including the holiday-ostinato warm-up, comping and walking-bass jam rows, and stride/ragtime review fallbacks.

Authored placement is not an affirmative teaching-use decision. Treating it as one here would recreate the exact implicit admission D3a was introduced to remove.

Required fix:

1. Route `runs`, `done`, `measure`, fallback rung/prerequisite, jam, and exposure automatic offers through one shared teaching-use admission before a music-promising generated item can enter the session card.
2. Keep the Library and explicit exploration exemption intact.
3. Keep the fact and verdict logic single-sourced; do not duplicate a parallel promise/approval test in each session path.
4. If admission removes the only candidate for a row, omit the row or use an already-valid alternative. Do not bypass admission merely to keep the card populated.
5. Add regressions proving `teaching: null` and `teaching: false` exclude such items from each automatic path, `teaching: true` restores them, and ordinary drills and notated items are unchanged.

This change is part of D3a rather than a later session-composition seam because the current handoff claims the universal automatic-offer boundary and the probe demonstrates a current breach of that same boundary.
